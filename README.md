# C++ Calculator

C++ console based scientific calculator that performs basic arithmetic operations.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division by zero handling
- User friendly console interface

## Concepts Used
- Variables
- Input and Output (cin/cout)
- Switch Statement
- If-Else
- Arithmetic Operators

## Sample Output

SIMPLE CALCULATOR 
Enter first number: 20
Enter operator (+, -, *, /): *
Enter second number: 5

Result = 100

## How to Run

1. Compile the program using a C++ compiler.
2. Run the executable.
3. Enter two numbers and select an operator.
